INSTALLATION (on Kali Linux)
────────────────────────────
1. Extract this zip file anywhere
2. Open a terminal in the extracted folder
3. Run: ./INSTALL.sh
4. Done! Desktop shortcut created.

USAGE
────────────────────────────
• Double-click "OSCP Toolkit" icon on your desktop
• Or open terminal and run:
    cd ~/OSCP-Toolkit
    ./START

WHAT IT DOES
────────────────────────────
• Opens terminal with ROOT shell (auto-login)
• Opens browser with cheatsheets
• Toggle "Send to Terminal" ON
• Click any command → appears in your terminal!
• Click "New Terminal" for more shells (sh1, sh2, sh3...)

TMUX SHORTCUTS
────────────────────────────
Ctrl+B c     Create new window
Ctrl+B n     Next window
Ctrl+B p     Previous window
Ctrl+B 0-9   Jump to window number
Ctrl+B w     List all windows
Ctrl+B d     Detach (keeps session running)
